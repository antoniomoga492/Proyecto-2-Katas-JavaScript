# Proyecto 2: Katas JavaScript

Ejercicios de JavaScript organizados en los tres bloques del proyecto.

## Estructura

- **`ejercicios-basicos-avanzados/`** — 42 ejercicios de lógica (variables, arrays, objetos, bucles, funciones). Se ejecutan con Node:
  ```
  node ejercicio-01.js
  ```

- **`ejercicios-dom/`** — 5 ejercicios de manipulación del DOM. Cada uno en su carpeta con `index.html` + `script.js`. Se abren en el navegador (F12 para ver la consola).

- **`ejercicios-es6-asincronia/`** — ejercicios de ES6+ (destructuring, spread, map, filter, reduce) y asincronía (fetch a APIs).
  - Los de lógica (1, 2, 3, 4, 6, 7) se ejecutan con Node.
  - Los que usan navegador (5, 8, 9) tienen su propia carpeta con `index.html` + `script.js`. Los 8 y 9 necesitan conexión a internet (llaman a APIs de Game of Thrones y PokeAPI).

## Cómo ejecutar

- **Archivos `.js` sueltos:** `node nombre-del-archivo.js`
- **Ejercicios con `index.html`:** abrir el HTML en el navegador y mirar la consola (F12).
